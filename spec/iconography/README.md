# Displacer Iconography

Displacer's SVG icon set uses arcane symbols, crystalline shapes, and runic forms.

## Style

- **Stroke:** 1.5px, round caps, round joins
- **Grid:** 24×24 base, preserves `currentColor`
- **Theme:** Arcane/crystalline — sharp angles, rounded caps, ink-trace linework
